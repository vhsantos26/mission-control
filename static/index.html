What do these numbers mean? — click to expand
  • Sessões — Conversas Claude Code distintas (1 JSONL = 1 sessão).
  • Turns — Quantidade de prompts (user → assistant pairs) no período.
  • Input — Tokens enviados ao modelo. Pricing baseline.
  • Output — Tokens gerados. Geralmente 5× mais caros que input.
  • Cache Read — Tokens reutilizados de cache (CLAUDE.md, contexto longo). ~10× mais baratos que input — números altos aqui são bom sinal.
  • Cache Create — Primeira escrita ao cache. Custa ~1.25× input. Quando crescem muito, indicam prompts iniciais grandes.
  • Custo — Estimativa em pricing API. Se você usa plano flat (Pro/Max), o custo real é o da assinatura — mude pricing_plan em ~/.mission-control/config.json.
