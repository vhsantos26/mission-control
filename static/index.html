What do these numbers mean? — click to expand
  • Calls — Each LLM API call recorded from an external tool (one POST to /api/intake/usage = one call).
  • Input — Prompt tokens sent to the model.
  • Output — Completion tokens returned by the model.
  • Cost — Calculated by the source tool using its own pricing. Cortex-routed calls use Al Jazeera's contracted rates, not public API prices.
  • Source — Tool that pushed this data (e.g. qe-workflows).
  • Agent — Sub-system within the tool responsible for the call (e.g. maintenance, validation).
