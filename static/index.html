What do these numbers mean? — click to expand
  • Sessions — Distinct Claude Code conversations (1 JSONL = 1 session).
  • Turns — Number of prompts (user → assistant pairs) in the period.
  • Input — Tokens sent to the model. Pricing baseline.
  • Output — Generated tokens. Generally 5× more expensive than input.
  • Cache Read — Tokens reused from cache (CLAUDE.md, long context). ~10× cheaper than input — high numbers here are a good sign.
  • Cache Create — First write to cache. Costs ~1.25× input. When they grow a lot, they indicate large initial prompts.
  • Cost — API pricing estimate. If you use a flat plan (Pro/Max), the real cost is your subscription — change pricing_plan in ~/.mission-control/config.json.
